# 🤖 MECORA 1.0

### Robotics & Engineering AI Assistant

**MECORA** is a personal AI assistant designed for **robotics, programming, embedded systems, and AI/computer vision**.

🌐 **Live:** https://mecora-1.onrender.com

### ✨ Features

* 🤖 Robotics assistance
* 💻 Python, C/C++ and programming
* 🔌 Embedded systems
* 🧠 AI & Machine Learning
* 👁️ Computer Vision
* 💬 Conversation memory
* 🖼️ Image analysis
* 📱 Responsive web interface
* 🔐 Secure API architecture

### 🛠️ Tech Stack

**Frontend**

* HTML5
* CSS3
* JavaScript

**Backend**

* Python
* Flask
* OpenRouter API

**Deployment**

* GitHub
* Render

### 📂 Project Structure

```text
mecora/
├── website/
│   └── index.html
├── server.py
├── requirements.txt
├── .gitignore
└── README.md
```

### 🚀 Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/mecora.git
cd mecora
pip install -r requirements.txt
python server.py
```

Then open:

```text
http://127.0.0.1:5000
```

### 🔐 Security

API keys are stored using environment variables and are **never exposed in the frontend or GitHub repository**.
